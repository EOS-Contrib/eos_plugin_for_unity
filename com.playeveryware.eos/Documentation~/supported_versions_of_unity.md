# <div align="center">Supported Versions of Unity</div>
---

The plugin was originally developed against [Unity 2021.3.16f1](https://dev.epicgames.com/docs/epic-online-services/release-notes#1163-cl32303053---2024-apr-09). 

The plugin is compatible with LTS versions of Unity 2021.3, 2022.3, 6.0, and 6.3.

For questions or issues related to integration or usage of Epic Online Services, Epic Games Developer Portal, or the EOS Plugin for Unity, please create a discussion on the [EOS Developer Community](https://eoshelp.epicgames.com).
